# Cuaderno

A personal Spanish notebook for everyday life in Spain, live at https://simonhannabuss.github.io/learn-spanish/

- **Practise**: phrase flashcards (English ↔ Spanish) and a verb conjugation drill
- **Phrases**: searchable phrasebook with Spain pronunciation and audio
- **Verbos**: every tense from the notes for 14 verbs, plus irregular participles
- **Correcciones**: fixes to the original notes, including Spain vs Latin American usage

It's a single `index.html` with no build step. Progress is saved in the browser's local storage.
